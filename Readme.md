Moodora – Every Feeling Has a Place 🌱

Moodora adalah website refleksi diri yang dirancang untuk membantu remaja mengenali, memahami, dan mengelola perasaan mereka. Website ini dibuat sebagai bentuk kepedulian terhadap masalah kesehatan mental yang sering dialami anak muda, seperti stres, kecemasan, kesepian, dan tekanan dalam kehidupan sehari-hari.

Melalui Moodora, pengguna dapat melakukan pemeriksaan suasana hati (mood check-in), mengisi kuesioner refleksi diri, menulis jurnal, serta mencoba aktivitas sederhana untuk menenangkan pikiran.

Moodora ditujukan terutama bagi remaja SMA/SMK. Website ini bukan alat diagnosis medis, melainkan media untuk membantu pengguna melakukan refleksi diri dan mendorong mereka mencari bantuan ketika diperlukan.

A. Judul & Deskripsi

- Nama Produk: Moodora
- Slogan: Every Feeling Has a Place.
- Kategori: Website Kesehatan Mental dan Refleksi Diri
- Target Pengguna: Remaja, khususnya siswa SMA/SMK.
- Tujuan: Membantu pengguna mengenali suasana hati, memahami perasaan, dan menemukan langkah sederhana untuk menjaga kesejahteraan emosional.

Fitur Utama

- Mood Check-in: Membantu pengguna mencatat suasana hati.
- Self-Reflection Questionnaire: Kuesioner untuk membantu pengguna mengenali kondisi emosionalnya.
- Mood Journal: Tempat menulis dan mencatat perasaan.
- Calm Corner: Aktivitas sederhana untuk membantu menenangkan pikiran.
- Mood Garden: Visualisasi suasana hati dalam bentuk taman.
- Emotion Constellation: Visualisasi perjalanan emosi pengguna.

B. Teknologi yang Digunakan

Moodora dikembangkan menggunakan teknologi web dasar tanpa memerlukan database.

Teknologi| Kegunaan
HTML5| Membuat struktur dan elemen halaman website.
CSS3| Mengatur tampilan, warna, tata letak, animasi, dan responsivitas.
JavaScript| Mengatur interaksi dan fungsi fitur website.
localStorage| Menyimpan data tertentu pada browser pengguna.
GitHub| Menyimpan dan mengelola kode sumber proyek.
GitHub Pages| Platform untuk mempublikasikan website.

Konsep Desain

Moodora menggunakan konsep Dark Modern UI dengan perpaduan warna navy, lavender, mint, dan abu-abu. Tampilan dirancang agar nyaman digunakan melalui perangkat ponsel maupun laptop.

D. Panduan Penggunaan

Moodora merupakan website berbasis HTML, CSS, dan JavaScript yang dapat dijalankan melalui browser.

1. Membuka Repositori

Kunjungi repositori GitHub Moodora melalui tautan berikut:

"https://github.com/brillian-ananta/Moodora" (https://github.com/brillian-ananta/Moodora)

2. Menjalankan Website Secara Lokal

1. Buka repositori Moodora di GitHub.
2. Pergi ke Page Action di bar atas GitHub.
3. Klik Page Build And Deployment.
4. Klik Link yang akan disediakan oleh GitHub.
5. Website Moodora akan ditampilkan dan dapat digunakan.

3. Menggunakan Fitur Moodora

1. Buka halaman utama Moodora.
2. Baca pengantar dan petunjuk penggunaan.
3. Pilih fitur yang ingin digunakan.
4. Isi mood check-in atau kuesioner sesuai kondisi yang dirasakan.
5. Gunakan fitur jurnal dan aktivitas relaksasi untuk melakukan refleksi diri.

Catatan: Moodora merupakan media refleksi diri, bukan pengganti diagnosis maupun konsultasi tenaga profesional.
