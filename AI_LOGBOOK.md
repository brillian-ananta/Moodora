Pokok masalah yang ingin diselesaikan Masalah pertama adalah tekanan akademik dan kecemasan terhadap masa depan. Banyak pelajar merasa harus memperoleh nilai bagus, menyelesaikan tugas, mengikuti ujian, dan menentukan pilihan kuliah atau pekerjaan. Ketika mereka merasa tertinggal dari teman-temannya, stres dapat meningkat dan waktu istirahat menjadi berkurang. MindSpace dapat membantu dengan menyediakan fitur pencatatan tingkat stres, pemecahan tugas menjadi langkah-langkah kecil, latihan relaksasi, serta refleksi harian agar pengguna dapat mengenali hal yang paling membebani dirinya. Masalah kedua adalah kesulitan memahami dan mengungkapkan emosi. Sebagian anak muda mengetahui bahwa dirinya sedang tidak baik-baik saja, tetapi kesulitan menjelaskan apakah yang dirasakan adalah sedih, kecewa, marah, kesepian, atau cemas. Ada pula yang takut dianggap lemah jika bercerita kepada orang lain. Solusinya adalah menyediakan fitur pemeriksaan suasana hati (mood check-in), jurnal pribadi, dan panduan mengenali emosi. Pengguna dapat mencatat perasaannya tanpa harus menceritakan masalah kepada orang lain terlebih dahulu. Masalah ketiga adalah tekanan sosial dan perbandingan diri di media sosial. Melihat pencapaian, penampilan, hubungan, dan gaya hidup orang lain dapat membuat sebagian remaja merasa dirinya kurang baik. Website dapat membantu pengguna mengidentifikasi situasi yang memicu perasaan tersebut, memberikan latihan membangun kepercayaan diri, dan menyarankan kebiasaan digital yang lebih sehat. Tujuannya bukan melarang penggunaan media sosial, tetapi membantu pengguna menggunakannya dengan lebih sadar. Masalah keempat adalah kurangnya akses terhadap informasi dan bantuan yang tepat. Tidak semua pelajar mengetahui perbedaan antara stres biasa dan kondisi yang memerlukan bantuan profesional. Mereka juga mungkin tidak tahu harus berbicara kepada siapa. MindSpace dapat menyediakan materi edukasi yang mudah dipahami, panduan berbicara dengan orang tepercaya, serta informasi layanan bantuan yang sudah diverifikasi. Dengan demikian, website tidak hanya membantu pengguna menenangkan diri, tetapi juga membantu mereka mengetahui kapan perlu meminta bantuan. \#\#\# 2\\. Rancangan teknis menggunakan HTML, CSS, dan JavaScript Kamu bisa mengembangkan MindSpace tanpa framework terlebih dahulu. Pendekatan ini cocok untuk pelajar SMA/SMK yang ingin memahami dasar pengembangan web sekaligus menghasilkan produk yang dapat didemonstrasikan. HTML — Struktur halaman Buat elemen semantik untuk navbar, dashboard, kartu mood, pertanyaan kuesioner, formulir jurnal, modal konfirmasi, dan footer. Gunakan satu halaman \`index.html\` dengan beberapa bagian yang ditampilkan sesuai menu aktif, sehingga pengguna merasakan pengalaman seperti aplikasi tanpa harus memuat halaman baru setiap kali berpindah menu. CSS — Tampilan dan responsivitas Buat \`style.css\` untuk sistem warna, font, tombol, kartu, formulir, animasi, dan layout responsif. Gunakan CSS variables seperti \`--color-primary\`, \`--color-background\`, dan \`--color-text\`, kemudian terapkan media query untuk tampilan ponsel, tablet, dan desktop. Dengan demikian, perubahan tema bisa dilakukan tanpa mengubah seluruh aturan CSS. JavaScript — Interaksi dan logika Buat \`script.js\` untuk perpindahan menu, pengisian kuesioner, pemilihan mood, grafik riwayat, timer pernapasan, checklist kebiasaan, dan operasi penyimpanan jurnal. Pisahkan fungsi berdasarkan tugasnya, misalnya \`renderQuestion()\`, \`saveMood()\`, \`renderMoodHistory()\`, dan \`deleteJournalEntry()\`, agar kode mudah diuji dan diperbaiki. Susunan folder proyek dapat dibuat seperti berikut: \`\`\`text mindspace/ ├── index.html ├── css/ │   └── style.css ├── js/ │   ├── script.js │   ├── questionnaire.js │   ├── mood.js │   └── storage.js ├── assets/ │   ├── images/ │   └── icons/ ├── README.md └── LICENSE \`\`\` File HTML menjadi halaman utama. File CSS mengatur desain, sedangkan file JavaScript dapat dipisahkan menjadi beberapa modul agar lebih terstruktur. Jika kamu ingin membuat proyek sesederhana mungkin, semua logika JavaScript boleh dimulai di satu file \`script.js\`, lalu dipisahkan ketika fitur mulai bertambah. Folder \`assets\` berisi gambar dan ikon yang kamu miliki atau yang lisensinya mengizinkan penggunaan. README berisi penjelasan proyek, fitur, cara menjalankan website, dan tautan demo. Pilih lisensi setelah menentukan apakah kamu ingin orang lain bebas menggunakan atau memodifikasi kode. Untuk penyimpanan, gunakan \`localStorage\` hanya bagi data yang memang diperlukan, seperti pilihan tema, catatan jurnal, dan riwayat mood. Buat struktur data yang konsisten, misalnya objek berisi waktu pencatatan, suasana hati, intensitas, dan kategori pemicu. Tangani kondisi ketika data belum tersedia, format data tidak valid, atau penyimpanan gagal. Jangan mengumpulkan kata sandi, nama lengkap, lokasi, atau data sensitif lain yang tidak diperlukan. Perlu diingat, \`localStorage\` bukan tempat penyimpanan yang terenkripsi. Website statis yang dipublikasikan di GitHub Pages juga tidak menyediakan database pribadi atau sistem autentikasi dengan sendirinya.
